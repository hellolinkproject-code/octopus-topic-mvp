# Mission 8 설계와 검증

## 목표와 범위

공통 쓰기 안내의 한계를 보완해 내 54번 답안에 대한 구체적인 피드백을 제공한다. 입력은 이미 저장된 600~700자 답안과 서버가 확인한 문제이며, 결과는 총평·장점·개선점·문장 수정·연습 팁이다. 사용자 이름과 이메일은 AI 입력에 넣지 않는다. 사용자가 답안 안에 개인정보를 쓰지 않도록 안내하고 전송 동의를 받는다.

최소 범위는 54번 첨삭 요청, 50P 사용, 결과 저장·조회, 성공·실패 UI이다. 53번 AI 첨삭, 점수 추정, 결제, 재작성 비교는 확장 과제다.

## 데이터와 동시성

기존 사용자 JSON을 유지하고 `answers[].aiFeedback`, `feedbackJob`, `feedbackUsage` 필드를 추가한다. 기존 기록은 마이그레이션 없이 읽는다. 과거 54번 저장 보상은 회수하지 않으며 신규 저장 보상만 0P로 변경한다.

1. ETag로 현재 사용자 문서를 읽고 소유권·포인트·횟수·진행 중 요청을 확인한다.
2. 조건부 쓰기로 작업 ID와 만료 시간(2분)을 예약한다. 포인트는 이 시점에 차감하지 않는다.
3. 저장 갱신 콜백 밖에서 외부 API를 1회 호출한다. 충돌 재시도로 API를 다시 호출하지 않는다.
4. 작업 ID를 재검증하고 결과와 포인트 차감을 같은 조건부 쓰기로 저장한다.
5. 외부 호출 실패 시 자신의 예약만 해제한다. 함수 중단으로 남은 예약은 2분 뒤 다시 요청할 수 있다.
6. 저장 응답을 잃으면 다시 읽어 완료 여부를 확인한다. 저장 상태도 확인할 수 없으면 성공·실패를 단정하지 않고 새로 확인하도록 안내한다.

동시에 퀴즈를 완료하거나 답안을 저장해도 변경 내용을 덮어쓰지 않도록 모든 사용자 쓰기에 동일한 ETag 갱신 함수를 사용한다. 충돌이 8회 지속되면 요청을 실패시켜 무한 재시도를 피한다.

## API 및 UX 실패 상태

| 조건 | 처리 |
| --- | --- |
| 로그인 없음 | 401, 로그인 안내 |
| 타인·없는 답안 | 404, AI 호출 없음 |
| 53번 또는 잘못된 입력 | 400, AI 호출 없음 |
| 전송 동의 없음 | 400, AI 호출 없음 |
| 50P 미만 | 409, 학습 링크 안내 |
| 동시 첨삭 요청 | 409, 저장 결과 새로 확인 |
| 하루 5회 소진 | 429, 다음 날 안내 |
| 키 미설정 | 503, 설정 중 안내, 차감 없음 |
| 제공자 실패·타임아웃 | 503/504, 예약 해제, 재시도 가능 |
| 거절·미완성·형식/인용 오류 | 422/502, 결과 저장·차감 없음 |
| 저장 상태 불명 | 503, 결과와 포인트 재조회 안내 |
| 수정 문장 없음 | 총평·구성 조언을 표시하고 빈 상태 설명 |

## 시연 순서

1. 로그인한다. 퀴즈를 완료하고 53번을 200~300자로 작성한다.
2. 획득한 포인트를 확인한다. 동일 문제 재요청으로 적립이 반복되지 않는지 확인한다.
3. 54번을 600~700자로 작성해 저장한다. 저장만으로 포인트가 오르지 않는지 확인한다.
4. ‘이 답안 첨삭받기’를 열고 50P 비용과 전송 동의를 확인한다.
5. 동의 후 첨삭을 요청한다. 버튼 비활성화·처리 중 안내를 확인한다.
6. 실제 키가 있는 환경에서 결과와 50P 차감을 확인한다. 새로고침·동일 요청 후 추가 차감이 없는지 확인한다.
7. 포인트 부족, API 실패, 로그인 만료, 두 탭에서 동시 요청을 검증한다.
8. 360px, 768px, 1280px 화면과 키보드로 동의·요청·이동을 확인한다.

## 보안 및 확장 판단

- 서버 키를 환경 변수로 보관하고 클라이언트에는 공개하지 않는다.
- 입력 답안 속 지시를 모델 명령으로 취급하지 않으며, 출력은 JSON 구조와 인용 원문을 검증한다. React 텍스트 렌더링으로 HTML을 실행하지 않는다.
- `store: false`로 Responses 객체 저장을 비활성화한다. 이것이 모든 제공자 로그 보존을 없앤다는 의미는 아니다.
- 모델과 프롬프트 버전을 결과에 저장해 향후 품질 비교가 가능하다.
- 현재 첨삭은 답안당 1회다. 답안 수정·버전별 재첨삭과 점수 검증은 후속 범위다.
